# 方案比较与用户选择增量验收

> [返回 BRIEF](../BRIEF.md) · [AC-06 / AC-15](../design/TECH_DESIGN.md#需求依据与验收) · 2026-10-18

用户追加要求：债务分析后至少给出全局最优与 MVP 两套合理方案，MVP 改动和影响面小、易实现；下一步让用户做选择题。

## 本次实现

- [Skill](../../../assets/skills/my-analyze-debt/SKILL.md) 将流程扩充为“证据分析 → 方案比较 → 有限任务 → 用户选择”。A 以当前目标和约束下的长期整体收益为依据；B 追求最小有效改动，两案均保持业务与安全底线。
- [模板](../../../assets/skills/my-analyze-debt/assets/templates/DEBT_ANALYSIS.tmpl.md) 增加动作、影响面、收益代价、实施验证、剩余债务与演进条件对照，任务关联 A / B / 共用；结尾给出具体 A / B / 暂缓补证选择题。
- 旧模板与旧报告按需补充比较和选择信息；未答复保持待选择，已有选择保留来源且不重复问。选择方向与实施授权分别记录；无治理项不编造方案。
- 同步 README、资产说明、Prompt 使用说明、行为用例及本 Feature 规格。资源数量、路径、catalog、manifest 和运行时实现未改变。

## 验证
