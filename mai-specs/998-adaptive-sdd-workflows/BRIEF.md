## 一句话描述

以原子 Skill 和场景 Prompt 组合 SDD 流程，按需求选择阶段、输入输出与模板，支持 simple 需求和分阶段交付。

## 背景

当前自动 Prompt 固定串行调用阶段 Skill，阶段入口普遍预设 PRD、技术方案等前置文档。2026-10-17 用户明确：Skill 提供原子能力，Prompt 负责场景组合；simple 需求仍按实际需要生成 PRD 和技术方案，使用简版模板。

## 关键决策

2026-10-18 方案评审通过，用户已授权编写测试计划、完整实现与验收；实现与独立代码评审已完成，当前进入验收（review）；242 项自动化与分发验收通过，30 个 Codex 场景结合自动化覆盖 AC-01～20，W-01 已关闭；其余宿主代表路径待可用运行环境。

- Prompt 决定阶段组合、顺序与连续推进；Skill 完成当前原子任务，返回产物、证据和缺口。
- 新增 `my-simple-feature` Prompt。需求充分时直接生成简版技术方案，需要梳理产品行为时先生成简版 PRD；微小且明确的低风险修改可直接执行。
- 采用 `simple / standard` 模板档位。PRD 与技术方案沿用既有产物路径；BRIEF 保存摘要、阶段选择及有效规格索引。
- Profile 采用唯一常量源；本 Feature 默认值由 BRIEF 维护，ROADMAP 显式展示。目录保持 `NNN-<slug>`，新索引五列、旧四列保留并在目标行说明展示规格。
- 档位调整保留 ID、路径和历史链接；单产物模板覆盖只记录到对应产物，不改变 Feature 默认值。索引同步失败须明确记录并按 BRIEF 恢复。
- 风险决定契约与评审强度，复杂度决定任务拆分，不确定性触发澄清或探索。复杂的低风险 Demo 可以分阶段使用 simple 规格。
- 继续保留项目约束、同一 Feature 接续、已有批注与证据；阶段是否执行、模板是否精简及交付是否通过分别判断。
- 原子能力和场景组合方向来自用户明确要求；具体接口、模板和兼容设计已通过方案评审，实施与验收证据将持续登记。
- 2026-10-18 增补供评审的代码设计（FR-12 / AC-21）：关键骨架与代表性逻辑用于认知、系统掌控和质量判断；少量内联，较多拆入方案同目录 Markdown。分发源与两档模板已更新，新增宿主行为评测待执行，历史通过证据仅覆盖原 AC。
- 2026-10-19 修复并复核 CR-W-03 / CR-W-04：附录安全命名与复用、实际 Profile 元数据及渲染校验；249 项自动化、13 组安装包检查和两个 Codex 命名兼容场景通过。AC-21 其余场景及跨宿主验证继续待验，Phase 保持 review，详见代码评审 §9。
