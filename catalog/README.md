# 内置 Skill 清单

`skills.json` 是名称、兼容别名、中文用途、类别与默认选择的登记源。CLI、配置解析和 Web 共同消费，个人扩展从个人库发现，无需登记到本文件。运行时提供 origin（builtin / personal）和 readOnly 字段，与 category 独立；内置名称及其别名禁止被个人导入覆盖。

`default` 标记 SDD 主流程项，供 Web 的主流程快捷选择使用；CLI 与 Web 新项目未保存固定清单时默认安装所有可用 Skill，已有偏好与项目选择优先。类别与安装策略独立。命名和头部规范见[使用指南](../docs/usage.md#维护个人资产)。开发工作区的 `skill-inventory.md` 保留外部参考比较，不随 npm 包分发。

`removedSkills` 登记明确停用的标识：这些名称不会再次进入目录或安装配置，即使个人库保留旧副本。升级时从既有选择中剔除，个人原文件保留；若需要继续维护同类个人能力，请使用新名称。
