# 技术方案 HTML 审阅版

由 `my-create-design` 默认调用，也可独立转换已有方案。收到上游交接的 Markdown 路径时直接使用。

## 找到方案

- 以用户指定的 Markdown 为准，支持简版、标准版和自定义文件名。只给 Feature 时，从该项目的 `mai-specs/FEATURE_LAYOUT.json` 中查找技术方案的产物路径，缺省为 `design/TECH_DESIGN.md`。有多个可能的输入且无法从会话确定时，请用户指定文件。
- 阅读主文及它实际链接的相关本地图表和代码附录，如 `CODE_DESIGN-02.md`。需要展示既有核心实现或补齐既有数据库字段时，仅读取方案明确指向的仓库内源码、模型或 DDL。拟议设计以方案为准。
- 将扩展名换成 `.html`，如 `order-refund.md` → `order-refund.html`，只写这一份文件。已有由本 Skill 生成的 HTML 可刷新。遇到手写文件、无法归属的手工编辑或软链接时，保留现场并说明冲突。Markdown、附录、源码和 Feature 状态保持原样。

## 组织内容

按“总览 → 展开 → 收束”编排。标题直接用业务或模块名。正文以图为主，每张图配一句图注，每节最多补几条影响理解的说明。删去 Feature、需求和任务编号、外部章节指代、来源追踪、验证记录、证据和测试细节。保留影响设计的权限、事务、失败处理和兼容规则，写在相应图或代码旁。技术路径和代码标识沿用原名。

| 阅读顺序 | 内容 |
| --- | --- |
| 首屏与背景 | 大标题、一句目标、**内联 SVG** 和简短背景。首屏 SVG 用短标签呈现本方案最值得先理解的技术关系。 |
| 设计原则与整体架构 | 提炼真正约束实现的原则。用 Mermaid `flowchart` 表达模块职责、依赖与边界。首屏讲主路径，详细架构补充协作关系，简单方案可合并。 |
| 数据结构 | 涉及数据库时，用 `erDiagram` 展示本次涉及的完整实体、关系与基数。每个字段写字段名、类型和中文含义，按实际标记 PK、FK、UK。可空性、默认值和复合约束放在图下。非数据库模型用类型图或短表。 |
| 数据流程 | 用 `sequenceDiagram` 表达参与方、调用顺序和返回值。用 `flowchart` 表达关键分支、状态与数据去向，保留影响结果的失败路径。 |
| 模块抽象 | 用 `classDiagram` 展示实际涉及的类、接口、类型、关键成员与依赖。函数式模块按模块职责和函数签名表示。 |
| 变更文件与核心代码 | 用高亮的 `diff` 代码块展示按路径组织的目录树和文件清单，以行首 `+`、`!`、`-` 标明新增、修改、删除，再写一句用途。保留源方案中明确的文件变更。核心片段按模块展示文件和符号，标明“现有实现”“拟议代码”或“伪代码”，关键分支加短中文注释，保留原有语义。 |
| 方案小结 | 用两三句话归纳本次交付的变化和最关键的设计取舍。 |

按内容选择图。没有数据库、类抽象或多方交互时省略相应图；简单方案仍保留首屏 SVG。若方案缺少应有的关系、字段或代码，简短说明具体缺口，保留已知内容。

## 视觉设计

先选出方案里最值得一眼看懂的关系，再决定首屏构图和页面风格。数据管道可以沿主链路展开，权限方案可以围绕信任边界组织。按图的密度选择并排、上下或全宽布局。

- **配色** 优先沿用项目主色，缺省跟随浏览器提供的系统强调色。用强调色标出关键路径或状态，让背景和次要元素留在中性色。状态同时配文字或形状，浅深主题都要读得清。
- **字体与层次** 选择中文显示清晰的字体，用字号、字重和间距拉开主标题、节标题、正文和图注。代码与文件路径用等宽字体。用留白和对齐划分章节，把底色、边框留给需要聚焦的图和代码。
- **图标** 从 Google Material Symbols 中按内容选图标，同一页统一线条风格。用图标帮助识别章节或状态，文字已足够清楚的地方可以省略。按实际用到的图标更新 CDN 的 `icon_names`。

## 生成与检查

- 以[单文件 HTML 模板](assets/templates/DESIGN_REVIEW.tmpl.html)为技术起点，替换全部占位符。示例 CSS、页面布局、首屏 SVG 和图表主题可按方案重写。复用 **Mermaid 11.16.0 + Highlight.js 11.11.1 + Google Material Symbols** 的 CDN 接入与渲染逻辑。页面直接通过浏览器 `file://` 打开，无需构建。仅在需要时通过同一 CDN 补载对应 Highlight.js 语言定义。
- 保留浅深主题响应、页内导航、短图注和局部横向滚动。沿用模板配色变量时，可将项目主色填入 CSS 的 `--project-accent`。
- 对代码、图源及其他来自 Markdown 的文字做 HTML 转义。图表只提取图定义，去掉配置指令和交互链接。ER 字段语法如 `uuid order_id FK "所属订单标识"`。为宽图拆分主题时保留跨图关联和字段覆盖。CDN 不可用时，首屏、图注、可展开的图源和纯文本代码仍可阅读。
- 正文用 `<section id="...">` 和对应的页内锚点。标题图标可用 `<span class="material-symbols-outlined" aria-hidden="true">account_tree</span>`。代码用 `<pre tabindex="0"><code class="language-实际语言">…</code></pre>`。
- 打开最终 HTML，核对首屏和各图、代码高亮、页内导航与窄屏显示。修复图语法和未替换的占位符后交付。答复给出 HTML 路径及影响审阅的内容缺口。

图表结构按下例填充。图注简述图表达的技术关系，图源中补充 Mermaid 的 `accTitle`。

```html
<figure class="diagram" data-diagram>
  <div class="diagram-output" tabindex="0" hidden></div>
  <figcaption>图的要点</figcaption>
  <details>
    <summary>查看图源</summary>
    <pre data-mermaid>转义后的 Mermaid 图源</pre>
  </details>
</figure>
```
